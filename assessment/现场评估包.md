## 二、物业四问（到场先问，记原话）

1. 安装验收文档/合同/保修卡在不在？能否复印或拍照（IP 规划表、初始密码常在其中）
2. 平时用什么管白名单/月租？有没有「云车场」商户账号、微信小程序或公众号入口？
3. 有没有遥控开闸的使用场景？流通中几把遥控？
4. 当初谁安装的？安装商联系方式？（安装商微信里可能有初始配置截图）

## 三、现场 SOP（约 45 分钟，非高峰时段）

1. 门岗报备，物业陪同到场
2. **立柱检修门**：先拍门锁状态 → 请物业开锁（若无需钥匙即开=发现）→ 门内全景、所有标签特写、控制器背面有无带天线小模块（RF 接收器）
3. **接网**：经同意接入车场网段（立柱内/道闸箱内交换机空口，或岗亭网口）
   ```
   ipconfig / ifconfig        # 记录自己拿到的网段
   arp -a                     # 找相机
   nmap -sn <网段>/24         # 扫存活
   nmap -sV -p 80,443,554,8000,8080,8899 <相机IP>
   ```
4. 浏览器开 `http://<相机IP>` 与 `:8080` → **登录页整页截图（含地址栏）** → 发给助手定固件家族
5. **Wi-Fi 扫描**：记录可疑配置热点 SSID（IPC-*/LPR-*/安快* 等），只记录不连接以外的操作
6. **防伪测试**：手机屏幕显示自己车牌照片，对准相机，记录反应（开闸/告警/无反应皆为有效数据）
7. 道闸箱：补拍锁状态；确认白色多芯信号线两端走向；只看不动
8. 全程日志：时间 / 动作 / 结果 / 截图文件名

## 五、已确认发现（直接进报告）

1. 【物理·高】道闸机箱无有效锁闭；控制器面板有物理起杆键；开闸干接点可短接（厂商 D119 说明书接线图背书：输入接口=低电平/开关信号）→ 物理接触即放行，无需任何凭据
2. 【物理·中】控制器参数菜单默认解锁码公开于说明书（F0.33：0000→0008，3 分钟有效）
3. 【物理·中（待现场确认）】控制器设计支持 433MHz 遥控接收+学习键配对；若接收模块在役，开箱者可配对自有遥控形成持久隐蔽 bypass
4. 【电气·中】箱内 220V 强电端子无防护盖、蛛网积尘，长期无巡检
5. 【管理·中】设备资产标签仅序列号二维码（ZBBP0122000581 / DZ700122000373），无台账化管理痕迹
