为什么写博客？

作为一名后端工程师，我希望通过博客：

  1. 记录学习过程 - 系统化整理技术知识
  2. 分享经验 - 帮助遇到类似问题的开发者
  3. 沉淀思考 - 深入思考技术背后的原理

博客技术栈

这个博客使用的技术：

  • Hexo - 静态站点生成器
  • Butterfly - 优雅的主题
  • GitHub Pages - 免费的托管服务
  • GitHub Actions - 自动部署
