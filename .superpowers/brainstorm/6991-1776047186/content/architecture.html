整体架构设计

基于 Hexo 的静态博客站点架构

技术栈选择

✓ 优势

  • Git 仓库管理所有内容
  • Markdown 文件易于编写
  • GitHub Actions 自动部署
  • 无需服务器运维成本
  • 支持 SEO 和快速加载

△ 注意

  • 每次更新需要重新生成
  • 动态功能受限(如评论)
  • 需要学习 Hexo 配置

目录结构

项目文件结构
fred.github.io/
├── source/              # 内容目录
│   ├── _posts/         # 博客文章
│   ├── _data/          # 数据文件(项目、片段等)
│   ├── about/          # 关于页面
│   └── projects/       # 项目页面
├── themes/             # 主题目录
│   └── butterfly/      # Butterfly 主题
├── scaffolds/          # 文章模板
├── public/             # 生成的静态文件
├── _config.yml         # 站点配置
└── .github/            # GitHub Actions
    └── workflows/
        └── deploy.yml  # 自动部署配置
