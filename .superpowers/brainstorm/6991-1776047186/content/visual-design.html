Git 部署流程

GitHub Actions 自动部署
工作流程：
1. 在本地写 Markdown 文章
2. Git push 到 GitHub 仓库
3. GitHub Actions 自动触发
4. 安装 Hexo、生成静态文件
5. 部署到 GitHub Pages
6. 访问 fred.github.io 查看更新

预计效果：每次 push 后 2-3 分钟完成部署
