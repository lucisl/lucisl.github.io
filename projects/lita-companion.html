陪玩与交易

Companion & Payment

从浏览陪玩师技能到下单、支付、服务完成与平台结算的完整交易链路。

  • 核心服务lita-earth / lita-payment / lita-basic
  • 充值渠道IPA / 第三方
  • 数据订单 / 充值
  • 风控risk 模块
← 返回 Lita 总览

这个域解决什么问题

陪玩交易把「用户需求」与「陪玩师服务」连接起来：用户浏览技能、下单、支付，陪玩师接单、履约，平台完成结算与风控。

它和充值、订单、风控绑在一起，是资金链路最密集的域，也是排查「钱去哪了」时最常进的域。

一次交易链路

浏览陪玩师 / 技能 → 下单（按小时 / 按局）→ 支付 → 陪玩师接单 → 服务进行 → 完成确认 → 平台结算 / 分成。

充值与支付

  • 应用内购买（IPA）与第三方渠道并存
  • 数仓里 channel in (1, 2) 表示 IPA 充值
  • 多币种、多支付厂商；支付回调必须幂等
  • 支付成功与入账要可对账，异常走补单

风控

  • 支付风控：异常渠道、频次、金额
  • 订单风控：刷单、虚假履约
  • 退款 / 拒付：需要状态机与对账

技术点与坑

  • 回调幂等：唯一订单号 + 状态机，重复回调不能重复入账
  • 金额单位：用最小货币单位，避免浮点
  • 结算分层：明细与汇总两层，支持按用户 / 陪玩师 / 天复盘
  • 海外合规：多币种、税务、渠道差异
