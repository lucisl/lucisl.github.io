送礼与虚拟礼物

Gifting

  • 核心服务lita-basic / litaroom

← 返回 Lita 总览

这个域解决什么问题

送礼是平台最核心的消费动作：用户用虚拟货币购买礼物，在语音房 / 直播间送出，触发特效、广播、榜单、家族积分、宝箱奖励，最终形成主播 / 陪玩师收益。

它同时是「钱」和「体验」：扣费必须准，特效和广播必须快，榜单必须实时，开奖必须可审计。

一次送礼链路

礼物配置 → 用户购买 / 持有 → 房间内送出 → 扣费与幂等 → 全屏特效 / 广播 → 榜单 / 家族积分 → 宝箱 / 盲盒开奖 → 收益结算。

礼物类型

  • 普通礼物：直接送出，计入榜单
  • 盲盒 / 礼物包：送出后开奖
  • 宝箱：送礼累计 / 活动产出，开启得奖励
  • 福袋 / 幸运币：房间内互动玩法
  • 装扮 / 头卡：身份展示型消费
  • 活动礼物：配合活动任务 / 榜单

技术难点

  • 高频写 + 高价值：扣费、库存、幂等、事务一致性
  • 广播与特效：不能阻塞主链路，失败要降级
  • 榜单：实时累计 + 定时结算 + 补发
  • 宝箱概率：配置化、可审计、防刷
  • 多端一致性：客户端展示与实际扣费要对账
