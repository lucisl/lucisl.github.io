# 在 fred.github.io 新增「大富翁」游戏（完整复刻好运之城机制）

## 目标
参考 ttkit.cn/game/monopoly「好运之城」（已完整试玩并记录全部规则与数值），在本仓库新增一个**独立静态游戏页** `/game/monopoly/`：机制 1:1 照搬、命名与文案原创、视觉跟随 DevKit 现有设计令牌、纯前端本地运行（无后端，单人 + 3 AI，不做联网匹配）。

## 已验证的核心机制（实现依据）
- 24 格环形棋盘，右下角起点，顺时针。起点经过/停留 +800（传送不领）；12 处街道 + 2 座车站（₵1200）+ 3 随机事件 + 2 道具商店（每次限购 1 张）+ 公园（+300 & 随机道具，背包满折 180）+ 慢行驿站（休息 1 回合）+ 两项固定支出（−280 / −450）。
- 初始资金 6000、每人 3 张随机初始道具；地块可建到 3 级，租金为基础 1 / 2 / 3.5 / 5.5 倍（实测 1100 地块 Lv0 租 185、Lv3 租 1018，建一级 480）；集齐同色地段租金 +50%，持有双车站车站基础租金翻倍；车站 0 级租 ~17% 地价（860→145、680→115 实测，数据表自定为 round(price×0.17)，建费 round(price×0.44)）。
- 9 种道具及价格：遥控骰 240 / 双骰 180 / 免租盾 320 / 双倍租金 340 / 建设卡 440 / 拆迁卡 380 / 传送卡 480 / 强购卡 520（按原值 135%）/ 路障 200；背包 6 格，每回合掷骰前可用 1 张、可另付费升级 1 处地产，顺序不限。
- 市况每 4 轮换一次，影响买地/建楼/租金价格（原创 4~5 种风向：平稳/繁荣/通胀/收缩/租赁潮，倍率写死在数据表）。
- 回合流程：掷骰前决策 → 掷骰移动（逐格结算经过起点）→ 落地处理（买地询问/交租/事件/商店/税费…）→ 结束回合。欠款时先卖建筑（建造费 60%）再卖地（原价 65%），可自动变现，仍不足则破产：剩余现金归债权人、地产归银行，人类破产当局结束，AI 破产淘汰。
- 全员行动一次 = 一轮；标准局 24 轮（另提供 12/36 局长选项），结束时按 现金 + 地产建筑原值 排名，资产相同看现金，再相同并列；只剩一人提前获胜。
- 存档 localStorage 单槽、自动更新、含未完成掷骰可恢复；×2 加速、暂停、音效开关、玩法说明弹窗。

## 原创命名原则
地块/道具/AI/文案全部重新起名（如 海风小筑→晨风小屋、艺术长廊→艺文长廊、遥控骰子→定点骰、林小满/顾星野/唐可可→三名原创角色），数值与机制保持一致；游戏标题拟用「大富翁 · 云栖之城」。

## 实施顺序
1. 核心引擎 + 数据表 + 单测（不动 UI，先保证规则正确）
2. AI + 整局模拟测试
3. 页面骨架与样式（静态渲染棋盘）
4. UI 接线：回合流程、弹窗、动画、加速/暂停、音效、存档恢复
5. build / 白名单 / 首页入口链接
6. 验证：`npm run check` 全绿 → 用浏览器完整玩一局快速局（含买地、收租、用道具、破产或结算），截图检查棋盘布局与文案，修视觉问题
